# Voice (Brand Voice Lock)

Brand voice is a system, not a vibe. Codify it so any writer or AI can hit it.

## The 4 axes (pick a position on each)

1. **Formal ← → Casual**: "We are pleased to introduce" vs "Meet the thing that finally works"
2. **Serious ← → Playful**: dry expertise vs winking humor
3. **Reserved ← → Loud**: understatement vs exclamation
4. **Traditional ← → Rebellious**: safe convention vs deliberate rule-breaking

Place your brand on each axis with an example sentence to anchor it.

## Sentence rhythm rules
- Average length: 12-15 words (short = punchy, long = thoughtful)
- Vary length — never 3 same-length sentences in a row
- Start with a verb 30% of the time
- End with the strongest word
- Contractions: yes / no (pick one and stick with it)

## Voice tests
Before shipping any copy, run:

1. **Substitute test**: replace our brand name with a competitor's. If the copy still makes sense, it's not our voice.
2. **Read-aloud test**: awkward = rewrite.
3. **The 15-word summary**: can you say what this is in 15 words that sound like us?
4. **The Slack test**: could this be a Slack message from the founder?
