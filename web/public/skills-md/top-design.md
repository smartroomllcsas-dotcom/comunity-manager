# Top Design

Push a working UI from 7/10 to 9.5/10. This is a finishing pass, not a rewrite.

## What Awwwards actually rewards
- **A single memorable moment**: unusual scroll, custom cursor, physics, or a hero interaction that makes people screenshot.
- **Editorial confidence**: asymmetry, oversized type, images that bleed, whitespace used as a design element.
- **Motion with intent**: nothing bounces for the sake of bouncing. Every animation has a job (guide, delight, react).
- **Custom everything**: no default form controls, no default focus rings, no default cursors, no default scrollbars — but ALL of it must still be accessible.

## Common upgrades
1. Custom cursor with hover states
2. Marquee/ticker with paused-on-hover
3. Text reveal on scroll (mask + translate)
4. Number counter with easing
5. Sticky sections with pinned parallax
6. Image hover with lens/mask/distortion
7. Draggable galleries with inertia
8. Font weight animation on hover
9. Grid that reflows mid-scroll
10. Sound design on interaction (subtle)

## Do not ship until
- Loads under 2s on 4G
- Runs at 60fps on a $300 laptop
- Every animation is `prefers-reduced-motion` aware
- All copy is proofread — typos kill polish instantly
- Every screen has been screenshotted at 4 breakpoints

Award juries scroll fast. If the first 3 seconds don't earn a screenshot, you lose.
