# Hooked UX (Nir Eyal's Hook Model)

Habit-forming products cycle users through four stages. Design each one deliberately.

## The 4 stages

### 1. Trigger
- **External**: notification, email, ad, word of mouth, app icon
- **Internal**: an emotion (boredom, loneliness, FOMO) that the user has learned to solve with your product

Design goal: earn the internal trigger by consistently delivering relief. Once "I'm bored" → "open Instagram" is wired, external triggers become optional.

### 2. Action
Simplest possible behavior in anticipation of reward. B = MAT (Behavior = Motivation × Ability × Trigger).
- Reduce friction (fewer taps, no login walls, one-thumb reachable)
- Increase motivation (streaks, social proof, curiosity gap)

### 3. Variable Reward
Fixed rewards lose power. Variability sustains engagement.
- **Rewards of the tribe**: social validation (likes, replies)
- **Rewards of the hunt**: information (feed refresh, deals, matches)
- **Rewards of the self**: mastery, completion, competence (streaks, levels, "days without")

### 4. Investment
User puts something in that increases future value:
- Data (preferences, ratings)
- Content (posts, photos)
- Followers (social capital)
- Reputation (reviews, karma)
- Skill (learned shortcuts)

Investment loads the next trigger. That's the loop.

## Design checklist
- What is the internal trigger you're targeting?
- What's the simplest action the user can take right now?
- Where is variability in the reward? (Warning: variable reward without utility = casino)
- What does the user leave behind that makes returning more valuable?

## Manipulation vs. habit
Ask: would the user thank you for building this? If not, you're building a slot machine, not a product. Ship the Nir Eyal manipulation matrix as a gut check before every feature.
