# Content Studio

Multi-format content pack production. Not a single post — a drop.

## Standard drop structure
For every idea, produce:
1. **Long-form** (blog / X thread / LinkedIn text post)
2. **Carousel** (8-10 slides for LinkedIn/IG)
3. **Reel/Short script** (30-60s vertical video)
4. **Quote graphic** (1-3 pull quotes for standalone posts)
5. **Newsletter version** (subject + preview + body)

## Carousel anatomy (LinkedIn/IG)
- **Slide 1 (cover)**: hook + promise. 6 words max. Contrast face or bold statement.
- **Slide 2**: the problem or context (1 line)
- **Slides 3-8**: one idea per slide, 15-25 words max, one visual anchor
- **Slide 9**: the payoff / synthesis
- **Slide 10 (CTA)**: save, share, or DM prompt

### Design rules
- One typeface family across the carousel
- One accent color, one background, one text color
- Numbered slides ("3/10") in the corner
- Consistent margins — never let text touch the edge
- Aspect: 4:5 (1080x1350) for feed, 1:1 for grid

## Reel script format
```
[0-3s HOOK]: visual + spoken hook, curiosity gap
[3-10s CONTEXT]: why this matters, credibility
[10-45s PAYOFF]: 3 points, each with cutaway
[45-60s CTA]: follow / save / one clear next step
```

Text overlay on every scene. Subtitles burned in. Music at -18dB under voice.

## Newsletter recipe
- Subject: <50 chars, curiosity-driven, no clickbait tells
- Preview text: complements subject, adds a detail
- Body: 200-400 words, one idea, one CTA
- P.S. line always — highest re-read rate

## Repurpose ladder
1 idea → 1 long-form → 3 carousels → 5 reels → 10 tweets → 1 newsletter. Never re-write from scratch — mine the same idea.

## Tools
- Design: Figma templates (build one, reuse forever)
- Video: CapCut for reels, Descript for long-form
- Scheduling: Buffer / Publer / native
- Analytics: Metricool for cross-platform
