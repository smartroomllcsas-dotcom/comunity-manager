### Paso 3: Estructura Visual (Jerarquía)

Todo creativo de Bliss sigue esta jerarquía:

```
1. HOOK VISUAL          → Lo primero que ve el ojo (imagen hero o título bold)
2. MENSAJE PRINCIPAL    → Montserrat ExtraBold, grande, dorado o blanco
3. SUBMENSAJE          → Poppins Light Italic, elegante, más pequeño
4. INFORMACIÓN         → Detalles (precio, fecha, servicios) en Montserrat SemiBold
5. CTA                 → Botón o texto de acción claro y prominente
6. LOGO BLISS          → Siempre al pie, sutil pero presente
```

### Paso 4: Estilo Visual

**Backgrounds:**
- Fondos oscuros (negro #010101 o teal #023a48) como base principal
- Gradientes sutiles: teal→negro, dorado→naranja→teal (para sunsets)
- Nunca fondos planos sin textura visual — usar gradientes, patrones geométricos sutiles o overlays

**Elementos gráficos:**
- Líneas finas doradas como separadores y marcos
- Esquinas doradas ornamentales para estilo premium
- Círculos y formas orgánicas para suavidad natural
- Patrones geométricos muy sutiles (opacity 3-8%) como textura de fondo
- Iconos minimalistas en dorado para features

**Fotografía (cuando se use):**
- Golden hour SIEMPRE preferida
- Profundidad de campo suave (bokeh en luces)
- Overlay oscuro (40-60% opacity) para legibilidad de texto
- Tomas aéreas/drone para escala y grandeza
- Close-ups de texturas: agua de jacuzzi, madera, telas, cocteles

## ESTRATEGIA DE META ADS (FACEBOOK + INSTAGRAM)

### El Creativo ES la Estrategia

En 2026, el **70-80% del rendimiento de un anuncio depende del creativo**, no del presupuesto. El algoritmo Andromeda de Meta usa tu creativo para determinar a quién mostrarlo.

### Formatos que Convierten para Bliss

**Para CONVERSIONES (reservas):**
1. **Imágenes estáticas 4:5** — 60-70% de conversiones. Foto espectacular + texto overlay mínimo
2. **Carruseles 1:1** — Recorrido visual: Card1=hook, Card2-4=amenidades, Card5=CTA
3. **Video UGC 7-15seg** — Estilo orgánico, iluminación natural, subtítulos

**Para AWARENESS (marca):**
1. **Video Reels 9:16** (8-19seg) — Contenido aspiracional, drone shots, golden hour
2. **Carruseles narrativos** — "5 razones para elegir Bliss"
3. **Video de producción** — Campañas estacionales

### Hooks de Video (Primeros 3 Segundos)

El sistema Andromeda evalúa los primeros 3 segundos POR SEPARADO. Hooks efectivos para Bliss:

1. **Drone Reveal** — Toma aérea amplia → zoom a las tiendas/jacuzzi
2. **POV de llegada** — Primera persona descubriendo el glamping
3. **Contraste dramático** — Ciudad gris → corte a paraíso natural
4. **Texto impactante** — "A 2 horas de [ciudad]" o "Esto cuesta menos de lo que piensas"
5. **Pregunta provocadora** — "¿Cuándo fue la última vez que dormiste bajo las estrellas... en sábanas de 600 hilos?"
6. **Reacción UGC** — Persona real abriendo la puerta con expresión de asombro
7. **Sonido ambiental** — Río, pájaros, fogata para inmersión sensorial

### Copy Framework para Ads

**Estructura que convierte:**
```
HOOK EMOCIONAL (primeros 125 caracteres — antes del "Ver más")
↓
BENEFICIO PRINCIPAL (la transformación que vivirá el huésped)
↓
PRUEBA SOCIAL o DIFERENCIADOR (amenidades únicas, reseñas)
↓
CTA CLARO (alineado con el objetivo)
```

**Copy por segmento:**
- **Parejas**: "Tu escapada romántica sin renunciar al lujo"
- **Familias**: "Aventura para los niños, descanso para ti"
- **Amigos**: "La mejor fiesta bajo el sol"
- **Wellness**: "Desconecta para reconectar"
- **Corporativo**: "Team building donde la inspiración fluye naturalmente"

**Headlines máximo 40 caracteres** para display óptimo en Meta.

### Segmentación Recomendada

**Intereses:**
- Camping, glamping, senderismo, ecoturismo
- Viajes de lujo, boutique hotels, Airbnb Luxe
- Bienestar, yoga, wellness retreats
- Gastronomía, experiencias culinarias
- Pickleball, deportes al aire libre

**Audiencias Lookalike:** Basadas en huéspedes anteriores (1-3%)

**Retargeting:**
- Visitantes web últimos 30 días
- Engagement de Instagram 75%+
- Abandonadores de página de reserva

### Presupuesto

- **Awareness**: $20-30 USD/día
- **Conversión**: $50-75 USD/día
- **Regla 70/30**: 70% prospección / 30% retargeting
- **Escalar cuando ROAS > 10:1**
- **Preparar campañas 6-8 semanas ANTES de temporada alta**

### UGC vs Profesional

| Etapa | Contenido | Razón |
|-------|-----------|-------|
| Awareness | UGC auténtico | Mayor CTR, menor CPM |
| Consideración | Profesional + BTS | Transmite calidad real |
| Conversión | UGC testimonial + profesional | Confianza + aspiración |
| Retargeting | Mix rotado | Evitar fatiga publicitaria |

**UGC genera 4x mayor CTR y cuesta ~50% menos por clic.**

### A/B Testing

Orden de prioridad:
1. Audiencia (mayor impacto)
2. Formato (video vs carrusel vs estático)
3. Hook del video (3-5 variaciones de gancho)
4. Copy (headline, texto, CTA)
5. Oferta (descuento vs valor agregado vs urgencia)

**Regla:** UNA variable por test, mínimo 7 días, presupuesto consistente.
